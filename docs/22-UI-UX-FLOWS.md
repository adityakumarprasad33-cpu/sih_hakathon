# UI/UX Flows

## Patient
```text
Sign up → Profile → Optional image → Pair device → Sensor check → Baseline → Home
```

## Doctor
```text
Sign up → Professional profile → Verification if required → Dashboard → Invite patient
```

## Consent
```text
Doctor invitation → Patient sees doctor + permissions → Approve/Reject → Active relationship
```

## Patient UI
Prioritize status, vitals, risk, alerts, device state and simple actions.

## Doctor UI
Prioritize patients needing attention, alerts, stale devices, filters and trend review.

Use text/icons in addition to color for risk severity.
