# Flutter Mobile App

## Responsibilities
- Firebase Auth
- onboarding
- device pairing
- BLE gateway
- local persistence/cache
- synchronization
- patient dashboard
- notifications
- emergency workflow
- Cloudinary profile-image flow
- AI companion

## Screens
Splash, Sign In, Sign Up, Recovery, Onboarding, Pair Device, Home, Live Health, Risk Details, History, Alerts, Emergency Contacts, AI Companion, Device Settings, Profile/Settings.
