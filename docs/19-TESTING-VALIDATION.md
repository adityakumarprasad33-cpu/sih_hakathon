# Testing and Validation

## Firmware
Sensor failures, reconnects, sampling, filtering, packet loss, watchdog, battery, storage and BLE.

## Mobile
Auth, pairing, offline mode, sync, notifications, Cloudinary and role separation.

## Web
Authorization, pagination, stale data, alerts and responsive UI.

## Firebase
Use Emulator Suite to test unauthenticated access, patient self-access, authorized doctor access, revoked access, cross-patient attacks, invalid writes and role escalation.

## AI
Measure sensitivity, specificity, precision, recall, F1, calibration, false alerts/day, latency, RAM/flash and power.

## Hardware
Compare readings with suitable reference equipment during validation. Plausible readings are not proof of clinical accuracy.
