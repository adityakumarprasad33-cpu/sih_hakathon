# Doctor Dashboard

## Main dashboard
Show:
- total active patients
- high-risk patients
- unacknowledged alerts
- stale/offline patients

## Patient list
Show patient identifier/name, risk state, last update, latest alert and device status.

## Patient detail
- profile
- current vitals
- signal quality
- risk scores
- trends
- alerts
- activity
- device status
- access/consent status

Use pagination and constrained queries. Never download the entire patient history into the browser.

Risk indicators must include timestamp and relevant confidence/context.
