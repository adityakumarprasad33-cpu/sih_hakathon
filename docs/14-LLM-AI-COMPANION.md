# LLM AI Companion

The LLM explains authorized health information in understandable language.

## Never
- diagnose
- invent measurements
- invent alerts
- override risk engine
- suppress emergency events
- fabricate clinical instructions
- imply certainty unsupported by data

## Flow
```text
Sensors → Edge → Risk Engine → Structured Facts → LLM → Explanation
```

Send only the minimum authorized data required.

Doctor-facing summaries should be grounded in measured data and clearly remain decision support, not diagnosis.
